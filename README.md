## 📂 Estructura del Proyecto

El código está organizado por asignaturas, cubriendo distintos paradigmas y niveles de abstracción:

### 1. ☕ Estructura de Datos y Algoritmos II (Java)
Diseño avanzado de algoritmos y resolución de problemas de optimización.
- **Ubicación:** `/Estructura de Datos y Algoritmos II`
- **Contenido Clave:**
  - **Divide y Vencerás:** Algoritmos geométricos y recursividad eficiente.
  - **Algoritmos Voraces (Greedy):** Estrategias para optimización de rutas y grafos (TSP).
  - **Programación Dinámica:** Resolución de problemas complejos mediante subestructuras óptimas.
  - **Búsqueda en Espacio de Estados:** Algoritmos Backtracking y Branch & Bound.

### 2. ☕ Estructura de Datos y Algoritmos I (Java)
Implementación y análisis de estructuras de datos no lineales y eficiencia algorítmica.
- **Ubicación:** `/Estructura de Datos y Algoritmos I`
- **Contenido Clave:**
  - **Árboles:** Implementación de Árboles Binarios de Búsqueda (BST) y Árboles AVL (Balanceados).
  - **Grafos:** Modelado de redes, estructuras de adyacencia y algoritmos de recorrido.
  - **Tipos Abstractos de Datos (TADs):** Diseño modular aplicado a sistemas de gestión (Bibliotecas, Usuarios).
  - **Testing:** Pruebas unitarias exhaustivas con JUnit 5.

### 3. ☕ Metodología de la Programación (Java)
Ingeniería de software, patrones de diseño y estructuras de datos fundamentales.
- **Ubicación:** `/Metodología de la Programación`
- **Contenido Clave:**
  - **POO Avanzada:** Herencia, polimorfismo, interfaces y programación genérica.
  - **Estructuras Lineales:** Implementación desde cero de Listas Enlazadas, Pilas y Colas.
  - **Persistencia:** Manejo de sistemas de ficheros y serialización (Patrón DAO).
  - **Calidad de Código:** Documentación (JavaDoc) y pruebas unitarias.

### 4. ☕ Introducción a la Programación (Java)
Los cimientos del pensamiento computacional y sintaxis Java.
- **Ubicación:** `/Introducción a la Programación`
- **Contenido Clave:**
  - Sintaxis fundamental, estructuras de control y bucles.
  - Lógica algorítmica básica y matemáticas aplicadas.
  - Manejo inicial de clases, objetos y Arrays.

### 5. ⚡ Multiprocesadores (C & Bash)
Computación de alto rendimiento (HPC), concurrencia y sistemas paralelos.
- **Ubicación:** `/Multiprocesadores`
- **Tecnologías:** C, MPI (Message Passing Interface), Pthreads, Shell Scripting.
- **Contenido Clave:**
  - **Simulaciones:** Modelado de ecosistemas (Wa-tor) y fractales (Mandelbrot).
  - **Paralelismo:** Implementación de soluciones en memoria compartida (hilos) y memoria distribuida (procesos).
  - **Análisis de Rendimiento:** Scripts de automatización y optimización de tiempos de ejecución (`gmon.out`).

### 6. 🔷 Programación de Servicios Software (C# / .NET)
Desarrollo de aplicaciones empresariales modernas y arquitectura backend.
- **Ubicación:** `/Programación de Servicios Software`
- **Tecnologías:** C#, .NET, XML, SQL Server.
- **Contenido Clave:**
  - **Arquitectura:** Patrones de diseño empresarial y separación de responsabilidades.
  - **Seguridad:** Sistemas de autenticación y gestión de usuarios.
  - **Datos:** Persistencia avanzada con XML y bases de datos SQL.
  - **Testing:** Pruebas unitarias en el ecosistema .NET.

## 🛠️ Requisitos de Ejecución

Para ejecutar los proyectos, asegúrate de tener instalado el entorno correspondiente:

| Lenguaje | Requisitos |
| :--- | :--- |
| **Java** | JDK 8 o superior (Recomendado JDK 17/21). IDE: IntelliJ IDEA, Eclipse o NetBeans. |
| **C** | Compilador GCC, librerías OpenMPI y Pthreads. Entorno Unix/Linux recomendado (o WSL). |
| **C#** | .NET SDK 6.0 o superior. IDE: Visual Studio 2022 o VS Code. |
