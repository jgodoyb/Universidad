# ☕ Estructura de Datos y Algoritmos I

Este módulo se centra en el estudio, implementación y análisis de estructuras de datos no lineales y la eficiencia algorítmica en Java. Se profundiza en el manejo de memoria dinámica y tipos abstractos de datos (TAD).

![JUnit](https://img.shields.io/badge/Junit5-25A162?style=for-the-badge&logo=junit5&logoColor=white)

## 🗂️ Contenido del Curso

El código está estructurado en ejercicios y prácticas incrementales:

### 🧩 Estructuras de Datos (Implementaciones Propias)
Ubicadas en `src/main/java/practicas/auxiliar`:
* **Árboles:**
    * `BSTree`: Árbol Binario de Búsqueda.
    * `AVLTree`: Árbol AVL (Auto-balanceado) para optimizar búsquedas.
* **Grafos:**
    * `Graph`: Implementación de grafos utilizando listas de adyacencia.

### 📚 Prácticas Principales
* **Práctica 01:** Gestión de juegos de cartas (Baraja, Jugador, Partida).
* **Práctica 02:** Análisis de frecuencia de palabras y gestión de usuarios mediante tablas hash o estructuras asociativas.
* **Práctica 03:** Sistema de **Gestión de Biblioteca**.
* **Práctica 04:** Análisis de redes de usuarios (**Network**) modelado con grafos.

## 🛠️ Tecnologías y Herramientas
* **Lenguaje:** Java (Uso intensivo de Genéricos y Colecciones).
* **Testing:** JUnit 5 para pruebas unitarias exhaustivas (`src/test/java`).
* **Documentación:** JavaDoc.

## 🚀 Ejecución de Tests
Para verificar la corrección de las estructuras de datos implementadas:

1. Abrir el proyecto en **IntelliJ IDEA** o **Eclipse**.
2. Navegar a la carpeta `src/test/java`.
3. Ejecutar `Practica04Junit5.java` (o la práctica deseada).
